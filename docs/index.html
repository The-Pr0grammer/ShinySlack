Frequently asked questions.

Everything you need to know before installing. Read the full privacy and technical FAQ for more detail.

Which Slack notifications does ShinySlack support?

Slack Desktop's own built-in notification windows on Windows, wherever they appear on your connected monitors. Alerts delivered only through Windows Notification Center / Action Center are not supported. Test with a real incoming notification.

Do I need to prime Slack or modify its sound cache?

No. The current live notification Router watches Slack's built-in notification windows; the earlier cache-priming setup is not part of the normal installation flow.

How do I launch ShinySlack after installation?

Use the branded ShinySlack Desktop or Start-menu shortcut. It opens the local dashboard and brings up the floating alert deck; you do not need to run scripts manually.

Does ShinySlack save my message text or sender names?

No. In the current release, accessible notification text is processed transiently for a short-lived SHA-256 deduplication fingerprint. Message bodies and sender names are not intentionally persisted. Local routing and event metadata are stored to provide the app's features.

Does ShinySlack upload my Slack data?

There is no ShinySlack telemetry service and the dashboard is bound to local loopback. An update check can contact GitHub for release metadata, without uploading Slack message content or channel configuration.

Can an alert take me directly to a Slack channel?

Yes, when that channel has a configured Slack deep link. ShinySlack opens the linked conversation using Slack's native URI handling.

What happens if I mute ShinySlack and close its windows?

In Router-owned audio mode, ShinySlack restores audible notifications after neither the dashboard nor the floating deck has been active for roughly 90 seconds. Muting remains intentional while either interface is active. The deck shows a red volume warning when muted or very low. Native Fallback mode is not changed by this safeguard.

Will alerts disappear automatically?

The floating deck supports individual dismissal, hide/reopen without clearing cards, compact/locked/auto growth modes, up/down expansion, and a configurable auto-dismiss option. Activity separately displays recent live routing events.

Can ShinySlack recover notifications from while my PC was off?

Not in the current release. Offline recovery remains under development and will require its own privacy, consent, and retention design. Recovered channel activity would not necessarily be identical to notifications Slack would have shown.

Is ShinySlack affiliated with Slack?

No. ShinySlack is an unofficial companion app. Use it only when permitted by your device and workplace policies.
