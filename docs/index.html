Built to fail closed.

ShinySlack does not blindly write into Chromium cache files. It verifies known payloads before patching and leaves unfamiliar cache state alone.

Local-only

The web-looking UI runs on 127.0.0.1. Your sound does not get uploaded to a ShinySlack server.

SHA-256 verified

The patch flow locates and verifies the exact stock/custom sound payload before cache writes.

Self-healing watcher

The watcher checks periodically and repairs stock sound when Slack is safely closed.

SLA-safe behavior

The watcher does not force-close an active Slack session during routine checks.

Beta: ShinySlack is an unofficial Slack customization and modifies local application cache data. Slack updates can change cache behavior. Use it only where your device/workplace software policy allows it.
